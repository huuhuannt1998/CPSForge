\begin{abstract}
Most LLM-for-CPS security studies evaluate attacks and defenses offline. We present \textbf{CPSForge}, a framework that places a local LLM as a man-in-the-middle agent in real PLC communication, automating both red team (attack injection) and blue team (write interception) on the live tag stream. The same model, context pipeline, and observation loop serve both roles---differing only in the prompt. The framework is configuration-driven: any PLC-connected plant can be analyzed via a scene YAML; no code changes required.

We evaluate CPSForge on three Factory~I/O scenes connected to a real Siemens S7-1200 PLC across 333 runs, studying context depth, closed-loop feedback, defense configuration, model choice, fine-tuning, and frontier model scaling. Key findings: the online MITM achieves up to 54\% ASR (Qwen2.5-3B) and 100\% ASR (GPT-4o-mini) on Sorting by Weight under minimal context, while the static one-shot LLM generates zero valid proposals; the LLM defender blocks 100\% of attacks on Sorting by Height, including cross-model blocking of frontier-model proposals, but exhibits 95--100\% false-positive rate on legitimate writes; ASR scales with model size (0\% at 1.7B, 14\% at 3B, up to 100\% for GPT-4o-mini); the self-deterrence effect observed with 3B models under rich operational context vanishes entirely at frontier model scale; and QLoRA fine-tuning on real PLC traces improves red team ASR from 0\% to 36.7\% on Level Control while maintaining 100\% blue team blocking. Within this evaluation scope---a single PLC model with software-emulated plants (15--35 tags)---CPSForge is the first framework to use a local LLM as a live MITM for automated CPS red/blue team analysis.
\end{abstract}
